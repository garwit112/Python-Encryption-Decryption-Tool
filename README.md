# TextCrypt-CLI

A simple Python command-line application for encrypting and decrypting text. The project demonstrates basic encryption logic, file operations, and user interaction through a menu-driven interface.

## Features
- Encrypt text input
- Decrypt stored encrypted text
- Save encrypted data to a file
- Simple command-line interface
- Beginner-friendly Python project

## Technologies Used
- Python
- Random Module
- OS Module
- File Handling
